# 账单管理系统

一个基于 React + Node.js 的个人账单管理系统，支持微信、支付宝账单导入。

## 📋 功能特性

- ✅ 支持微信、支付宝账单导入
- ✅ 智能分类识别
- ✅ 数据统计图表
- ✅ 账单筛选和搜索
- ✅ 批量操作
- ✅ 响应式设计

## 🛠 技术栈

- **前端**: React, Ant Design, ECharts
- **后端**: Node.js, Express, MySQL

## 🔧 开发环境

### 后端开发
```bash
cd backend
npm install
npm run dev
```

### 前端开发
```bash
cd frontend
npm install
npm start
```
